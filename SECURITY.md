# Security Policy

Chronix is a self-hosted automation system. Please do not publish working exploits, private keys, live credentials, or sensitive deployment details in public issues.

To report a security issue, email security@chronixhq.com with:

- affected version or commit,
- impact and reproduction steps,
- relevant logs or screenshots with secrets removed,
- whether the issue affects a local-only deployment or a remote boundary.

We will acknowledge credible reports and coordinate fixes in the public repository when it is safe to do so.
