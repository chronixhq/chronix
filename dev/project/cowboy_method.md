# Cowboy Methodology for Chronix Development

A lightweight Agile framework adapted for solo development by Dan Sherwin.

## Principles

- Iterative, milestone-driven progress
- CLI-first, single-binary UX
- No team overhead—just discipline and focus
- Planning lives in `dev/project/`, not your head

## Workflow

- Use a single `main` branch (trunk-based)
- Milestones tracked via markdown
- Backlog is a living file
- Postmortems after each release

See `v0.1_milestone.md` for the first cycle.
